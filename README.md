# Fazenda Minas – Gado de Leite (Montes Claros/MG)

Mundo 3D estilo Minecraft para andar em primeira pessoa por uma fazenda de leite de 200 ha, com ovinos/caprinos.

## Como usar
Abra o `index.html` no navegador (computador). Precisa de internet, pois o three.js é carregado do cdnjs.

## Controles
- WASD: andar · Shift: correr · Espaço: pular · C ou Ctrl: agachar
- Mouse: olhar · Tab: alterna 1ª, 3ª e 2ª pessoa · E: interagir (sobe e desce do trator) · F: mandar vaca sozinha · G: soltar vacas · Q ou clique: soco · N: novo dia · Esc: solta o mouse

## Publicar no GitHub Pages
Settings > Pages > Deploy from a branch > `main` / root.

## Personagens
Ao entrar: escolha entre personagem#1, #2 e #3, depois monte o visual (cabelo, mechas, pele, chapéus, lenços, colares, camisas, jaquetas, calças, bermudas e calçados), com paleta de mais de 100 cores. A escolha fica salva no navegador.
